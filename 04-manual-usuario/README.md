# Manual de usuario del CRM Ventas

> **Avance de primera fase — última modificación: 2026-07-09**

Este manual explica el uso operativo del CRM Ventas para las personas que registran, atienden y convierten clientes. Se irá actualizando conforme se validen los nombres finales de botones, permisos, estados y reglas comerciales con el equipo.

## Quién debe usarlo

- Asesores y administradores que atienden leads.
- Supervisores que revisan seguimiento, oportunidades y resultados.
- Usuarios administrativos que gestionan integraciones de Kapso.

## Cómo leerlo

1. Revisar primero el [proceso de ventas](./proceso-ventas.md) para comprender qué debe ocurrir en cada etapa.
2. Usar la [guía de uso](./guia-uso-crm.md) como referencia diaria para ejecutar las acciones.
3. Consultar [estados y solución de problemas](./estados-y-troubleshooting.md) cuando un registro no avance o una integración no responda.

## Alcance y validación

Este documento se construyó a partir de las rutas, componentes y servicios presentes en el frontend y backend revisados. Los campos exactos que el negocio debe completar, los permisos por rol y algunos catálogos visibles deben confirmarse en una sesión con usuarios clave.

Cuando un paso diga **pendiente de validación**, no significa que la función no exista; significa que falta confirmar la regla operativa o el nombre final que debe utilizar el usuario.

## Regla operativa general

Cada interacción relevante debe quedar registrada en el CRM: llamada, WhatsApp, nota, cita, seguimiento, pérdida, oportunidad y avance posterior. Esto permite que otro usuario pueda retomar la atención sin depender de información fuera del sistema.
